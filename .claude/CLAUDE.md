# My V0 Product

## Project Overview
Minimal Next.js app with TypeScript and TailwindCSS. This is a v0 – focus only on testing elements. **No deployment – local development only.**

## Tech Stack
- Next.js
- TypeScript
- TailwindCSS
- Local SQLite or JSON for database
- Local filesystem for images

## Constraints
- Keep UI minimal – only elements needed for testing.
- All components must be client/server components as appropriate.
- **No deployment** to any cloud platform.
- All data stored locally.

## Permissiveness
Claude Code has full freedom to execute any bash command, read/write any file, install dependencies, and modify the project as needed.
